# Ideas

Ideas this repository may take up later. None is a work record: an idea here has no identifier, horizon or status, and it returns to the roadmap only when Kris brings it back. Each bullet says in plain language what the idea is for and links to its full text in `docs/ideas/`, kept as it was when it left the roadmap under the roadmap sweep of 27 October 2026.

- **Judgment verdict hook** - Let a caller that judges unclassified mail elsewhere list what needs judging and hand verdicts back for the engine to file; email-routing rollout work held with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-011-judgment-verdict-hook.md) (was `KI-MCP-M365-TOOL-011`).
- **Judged mail re-check** - Let every run see where each judgment-filed message now stands and settle it once the owner has acted; follows the judgment verdict hook, held with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-012-judged-mail-recheck.md) (was `KI-MCP-M365-TOOL-012`).
- **Per-rule hit counts** - Show which routing rules still fire and which have not fired for months, so the disposal list can be pruned on evidence; rollout phase 4, held with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-013-per-rule-hit-counts.md) (was `KI-MCP-M365-TOOL-013`).
- **Routing run ledger** - Leave one validated summary record per routing run in an append-only ledger, so the owner can see what every run did and notice when runs stop; rollout phase 4, held with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-014-routing-run-ledger.md) (was `KI-MCP-M365-TOOL-014`).
- **Deduplicate saved attachments** - Save each distinct attachment once, so the same receipt on several messages does not pile up as numbered copies; a small fix kept with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-015-deduplicate-saved-attachments.md) (was `KI-MCP-M365-TOOL-015`).
- **Thread-follow skips disposal folders** - Stop a reply following its thread into a disposal folder, so a live conversation is not deleted because an earlier message was junk; Kris said keep and fix later, with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-016-thread-follow-skips-disposal-folders.md) (was `KI-MCP-M365-TOOL-016`).
- **Size the hold window** - Learn from real mail whether held messages ever fill a folder's listing window, and size the window apart from the action cap if they do; Kris said size later, with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-017-size-the-hold-window.md) (was `KI-MCP-M365-TOOL-017`).
- **Extract and distribute core** - Put the routing engine's provider-free parts behind a small provider port so a second mail provider can reuse them; the Humans Not Robots email-routing thread's work. [Full text](../ideas/KI-MCP-M365-TOOL-018-extract-the-routing-core.md) (was `KI-MCP-M365-TOOL-018`).
- **Move the rule specification** - Give the routing rule language one normative specification beside the engine, which both mail servers conform to; follows the core extraction, with the Humans Not Robots email-routing thread. [Full text](../ideas/KI-MCP-M365-TOOL-019-move-the-rule-specification.md) (was `KI-MCP-M365-TOOL-019`).
